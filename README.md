# Curso completo de Claude

Curso do uso básico do Claude até agentes em produção, em 158 horas: 5 níveis, uma ponte de programação em Python e 39 módulos.

Os exemplos e exercícios usam o trabalho de um analista de dados de CRM e marketing: tratamento de bases para importação, segmentação de público, e-mails e landing pages em HTML, relatórios de campanha, estudos de público e de mercado.

| --- | --- | --- | --- |

A ementa completa, com objetivo, conteúdo e exercício de cada módulo, está em [Ementa: Curso Completo de Claude](https://claude.ai/artifact/Rwj1rQMrJJyRVJBjrqp6HV).

## Como estudar

1. Siga a ordem das etapas. O projeto de cada uma é a porta de entrada da seguinte.
2. Em cada módulo, leia a aula, faça o exercício e responda à checagem rápida sem olhar as respostas.
3. Guarde o entregável de cada exercício. Vários são reaproveitados nos módulos seguintes.
4. Só avance de etapa depois de concluir o projeto e conferir os critérios de aprovação.

## Formato de cada módulo

- **Objetivo:** o que você passa a conseguir fazer.
- **Por que importa no seu trabalho:** onde o assunto aparece na rotina.
- **Conteúdo:** a aula.
- **Exemplo aplicado:** o conteúdo em uma situação de CRM e marketing.
- **Exercício:** passos, entregável e critério de conclusão.
- **Erros comuns:** o que costuma dar errado.
- **Checagem rápida:** perguntas com resposta para autoavaliação.

## Dados dos exercícios

Todos os arquivos nas pastas `dados/` são fictícios. Nomes de feiras, disparos e números foram inventados para o curso, no formato de exportações reais de CRM.
