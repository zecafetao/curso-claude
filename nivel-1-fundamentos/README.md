# Nível 1 — Fundamentos

**Carga:** 12 h (10 h de módulos + 2 h de projeto) · **Pré-requisito:** nenhum

Ao final deste nível, você usa o app Claude com segurança no dia a dia e sabe quando confiar ou desconfiar de uma resposta.

## Módulos

| Módulo | Carga | O que você passa a fazer |
| --- | --- | --- |
| [1.1 Como um modelo de linguagem funciona](1.1-como-um-modelo-funciona.md) | 2 h | Prever quando uma resposta precisa de checagem |
| [1.2 Família de modelos](1.2-familia-de-modelos.md) | 1 h | Escolher o modelo certo para cada tarefa |
| [1.3 O app Claude na prática](1.3-app-claude-na-pratica.md) | 3 h | Usar conversas, anexos, Projects, Artifacts, busca e memória |
| [1.4 Prompting básico](1.4-prompting-basico.md) | 3 h | Escrever pedidos claros e consertar uma resposta ruim |
| [1.5 Uso responsável](1.5-uso-responsavel.md) | 1 h | Proteger dados pessoais e validar o que vai para o cliente |
| [Projeto do nível](projeto.md) | 2 h | Montar um assistente para o relatório mensal de e-mail |

## O que você precisa

- Uma conta no app Claude (claude.ai ou aplicativo de desktop). Os recursos disponíveis variam por plano; confira em [claude.com/pricing](https://claude.com/pricing).
- Os arquivos da pasta [`dados/`](dados/), todos fictícios:

| Arquivo | Usado em | O que é |
| --- | --- | --- |
| `desempenho_email_outubro.csv` | 1.4 e projeto | Exportação de desempenho por disparo de uma feira fictícia |
| `briefing_campanha.md` | 1.2, 1.3 e 1.4 | Briefing de uma campanha de credenciamento |
| `layout_importacao_crm.md` | 1.3 e 1.4 | Layout de importação de contatos em um CRM |
| `resumo_estudo_publico.md` | 1.3 e 1.4 | Resumo de um estudo de perfil de expositores |

## Entregáveis do nível

1. Tabela de checagem de 10 respostas (1.1).
2. Comparação de dois modelos no mesmo pedido (1.2).
3. Um Project com três documentos e uma landing page gerada como Artifact (1.3).
4. Cinco pedidos reescritos, com o antes e depois (1.4).
5. Checklist pessoal de uso responsável (1.5).
6. O assistente do relatório mensal, aprovado no gabarito (projeto).
