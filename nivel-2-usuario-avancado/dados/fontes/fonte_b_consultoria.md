# Tendências de Compra de Embalagens 2026

**Fonte fictícia, criada para o curso.** Consultoria Modelo. Pesquisa com 400 indústrias usuárias de embalagens, realizada em novembro de 2025.

## Tamanho do mercado

A consultoria estima o mercado de embalagens em R$ 152 bilhões em 2025. A estimativa inclui o segmento de máquinas e equipamentos para embalagem.

## Troca de fornecedores

62% das indústrias pretendem trocar ou adicionar ao menos um fornecedor de embalagens nos próximos 24 meses.

## Critérios de escolha de fornecedor

Pergunta de resposta múltipla; os percentuais somam mais de 100%.

| Critério | Citações |
| --- | --- |
| Custo | 71% |
| Prazo de entrega | 55% |
| Sustentabilidade | 48% |
| Inovação | 31% |

## Como as indústrias descobrem novos fornecedores

Pergunta de resposta múltipla.

| Canal | Citações |
| --- | --- |
| Indicação | 58% |
| Feiras de negócios | 46% |
| Busca online | 44% |
| Representantes comerciais | 37% |

## Sustentabilidade

41% das empresas têm meta pública de uso de embalagens recicláveis. Entre as empresas de grande porte, a proporção é de 68%.

## Comércio eletrônico

A demanda por embalagens de envio para comércio eletrônico cresce 9% ao ano desde 2022.
